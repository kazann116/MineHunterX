# MineHunter X — ограничения MVP

- **Не антивирус.** Нет сигнатурной базы, облачной репутации, песочницы и гарантированного
  обнаружения руткитов. Отсутствие находок не означает отсутствия угроз.
- **Без прав администратора** часть процессов видна частично (нет пути, памяти, времени
  создания). Программа сообщает об этом в «Источниках данных» и в карточках находок.
- **Температура процессора** без драйвера ядра Windows не отдаёт. MineHunter своего драйвера
  не устанавливает; температура CPU показывается, только если пользователь сам запустил
  LibreHardwareMonitor или OpenHardwareMonitor (их WMI), иначе — «нет данных» с пояснением.
  Троттлинг процессора определяется без драйвера — по счётчику «% Performance Limit».
- **Видеокарта**: загрузка по процессам и движкам — счётчики Windows (Windows 10 1709+,
  драйвер WDDM 2.0+); температура — D3DKMT (WDDM 2.4+), для NVIDIA — также NVML. Встроенные
  видеокарты часто не сообщают температуру. Вентиляторы не показываются: документированного
  способа их опроса нет.
- **Температура накопителей** — только у устройств, которые отдают её Windows (большинство
  NVMe и SATA); у USB-накопителей и некоторых RAID-контроллеров её нет.
- **Пороги температуры**: если производитель не сообщил порог, используются консервативные
  значения (видеокарта 87 °C, накопитель 65 °C, процессор 90 °C).
- **Командные строки** читаются через WMI только для нагруженных процессов (по умолчанию от 3%
  CPU); у процессов других пользователей командная строка недоступна.
- **Проверка подписи без сети**: отзыв сертификатов учитывается только если сведения уже есть
  в системном кеше Windows.
- **Профиль нормы** формируется за период обучения (по умолчанию 3 дня, не меньше 1 800 снимков
  на контекст); до этого сравнение с нормой недоступно и уверенность находок ниже.
- **Карантин** не входит в MVP. Доступны: открыть расположение, проверить в Microsoft Defender
  (только отчёт), остановить процесс после подтверждения.
- **Числовые цели** (≤ 2% CPU в простое, ≤ 200 МБ памяти, 8 часов без сбоев) — цели
  проектирования; результаты измерений на конкретной машине приведены в README и не являются
  гарантией для любого оборудования.
- **Отчёт о ложных срабатываниях** построен на синтетических сценариях
  (`docs/false-positive-report.md`); на реальных компьютерах возможны иные ситуации —
  для этого предусмотрены исключения и настраиваемые пороги.
