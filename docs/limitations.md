# MineHunter X — ограничения

- **Не антивирус.** Нет сигнатурной базы, облачной репутации, песочницы и гарантированного
  обнаружения руткитов. Отсутствие находок не означает отсутствия угроз.
- **Без прав администратора** часть процессов видна частично (нет пути, памяти, времени
  создания). Программа сообщает об этом в «Источниках данных» и в карточках находок.
- **Температура процессора** без драйвера ядра Windows не отдаёт. MineHunter своего драйвера
  не устанавливает; температура CPU показывается, только если пользователь сам запустил
  LibreHardwareMonitor или OpenHardwareMonitor (их WMI), иначе — «нет данных» с пояснением.
  Троттлинг процессора определяется без драйвера — по счётчику «% Performance Limit».
- **Видеокарта**: загрузка по процессам и движкам — счётчики Windows (Windows 10 1709+,
  драйвер WDDM 2.0+); температура — D3DKMT (WDDM 2.4+), для NVIDIA — также NVML. Встроенные
  видеокарты часто не сообщают температуру. Вентиляторы не показываются: документированного
  способа их опроса нет.
- **Температура накопителей** — только у устройств, которые отдают её Windows (большинство
  NVMe и SATA); у USB-накопителей и некоторых RAID-контроллеров её нет.
- **Пороги температуры**: если производитель не сообщил порог, используются консервативные
  значения (видеокарта 87 °C, накопитель 65 °C, процессор 90 °C).
- **Командные строки** читаются через WMI только для нагруженных процессов (по умолчанию от 3%
  CPU); у процессов других пользователей командная строка недоступна.
- **Проверка подписи без сети**: отзыв сертификатов учитывается только если сведения уже есть
  в системном кеше Windows.
- **Профиль нормы** формируется за период обучения (по умолчанию 3 дня, не меньше 1 800 снимков
  на контекст); до этого сравнение с нормой недоступно и уверенность находок ниже.
- **Карантин и откат.** Файлы перемещаются в `%LOCALAPPDATA%\MineHunterX\Quarantine` (не
  шифруются и не «обезвреживаются» — просто убираются с прежнего места); значения реестра,
  тип запуска служб и состояние заданий сохраняются для отката. Файлы из папки Windows,
  сам MineHunter X и критические службы не трогаются. Подписки WMI и строки hosts программа
  не меняет — даёт инструкции. Для объектов в HKLM, служб и чужих заданий нужны права
  администратора. Перемещение занятого файла не выполняется (процесс нужно остановить).
- **События запуска процессов (ETW)** доступны только с правами администратора (или в группе
  «Пользователи журналов производительности»); без них журнал запусков ведётся по изменениям
  списка процессов между опросами: процессы, прожившие меньше интервала опроса, в него не
  попадают, а время завершения известно с точностью до интервала. Сеанс ETW один на компьютер:
  второй экземпляр программы перезапустит его.
- **Параметры запуска** в журнале событие Windows не передаёт: командная строка читается у процесса
  сразу после запуска (NtQueryInformationProcess). У процессов, завершившихся раньше, и у защищённых
  системных процессов параметров нет. Параметры хранятся в локальной истории только при включённом
  хранении путей процессов и не длиннее 2048 символов; в отчёты они не попадают.
- **Мощность и стоимость электроэнергии** — только для видеокарт NVIDIA (датчик драйвера через
  NVML). Мощность процессора и остального компьютера без драйвера ядра недоступна, поэтому
  оценка стоимости относится только к видеокарте.
- **«Что изменилось»** отсчитывается от начала наблюдения: всё, что было на компьютере в первые
  30 минут работы MineHunter X, считается исходным состоянием (в том числе уже имевшийся
  вредоносный автозапуск — его оценивает анализатор, а не учёт изменений).
- **Английский язык** охватывает интерфейс, объяснения находок, рекомендации, отчёты и сообщения
  источников данных. На русском остаются несколько служебных пояснений коллектора признаков
  вмешательства (например, «сценарий», «файла нет на диске»), по которым анализатор сопоставляет
  данные, а также записи, сохранённые в истории до смены языка. Язык меняется после перезапуска.
- **Диски.** Износ, ошибки и наработку отдаёт сам диск через Windows (Storage Management);
  без прав администратора эти сведения обычно недоступны, у части дисков (USB, RAID, некоторые
  SSD) их нет вовсе. Журнал здоровья NVMe читается и без прав администратора (раз в минуту).
  SMART дисков SATA — только с правами администратора и раз в 10 минут, чтобы не будить лишний раз
  спящие диски; для дисков за USB-мостом и RAID-контроллером атрибуты не запрашиваются. Износ
  SATA SSD по SMART не вычисляется: у каждого производителя свой атрибут. Температуру сообщают не все диски. «Кто читает и пишет» — это все операции
  ввода-вывода процесса (GetProcessIoCounters): в основном диск, но также сеть и устройства; к
  конкретному диску чтение процесса не привязывается. Сразу после запуска MineHunter сам читает
  диск несколько минут — считает SHA-256 файлов запущенных программ (помечен в списке).
- **Проверка файлов** не заменяет антивирус: она ищет признаки майнеров по именам, расположению,
  атрибутам и строкам внутри файлов. Содержимое читается только у конфигураций и сценариев
  (до 256 КБ) и у программ из нетипичных мест или скрытых (до 128 МБ); упакованный или
  зашифрованный майнер без других признаков может остаться незамеченным. Папка Windows
  проверяется только в Temp, Fonts и Debug. Полная проверка нескольких больших дисков занимает
  от нескольких минут до десятков минут.
- **Проверка обновлений** выключена по умолчанию; при включении программа обращается только к
  `api.github.com` (последний выпуск репозитория) и ничего не скачивает сама.
- **Числовые цели** (≤ 2% CPU в простое, ≤ 200 МБ памяти, 8 часов без сбоев) — цели
  проектирования; результаты измерений на конкретной машине приведены в README и не являются
  гарантией для любого оборудования.
- **Отчёт о ложных срабатываниях** построен на синтетических сценариях
  (`docs/false-positive-report.md`); на реальных компьютерах возможны иные ситуации —
  для этого предусмотрены исключения и настраиваемые пороги.
